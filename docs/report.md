## Описание программы
Программа реализует работу с массивом структур ZNAK, содержащих:
- Name – фамилия и имя
- ZOD – знак зодиака
- DATE – дата рождения (год, месяц, число)

Функциональность:
1. Ввод с клавиатуры 10 записей
2. Упорядочивание по дате рождения
3. Поиск по знаку зодиака

## Структура проекта (модель КИС)
- `src/znak.h` - интерфейс (объявление структуры и функций)
- `src/znak.c` - сервер (реализация функций)
- `src/main.c` - клиент (взаимодействие с пользователем)
