# tpmp-lab2-task3 - Работа со структурами в C

## Overview
Данная программа реализует работу с массивом структур ZNAK, содержащих информацию о людях:
- Name – фамилия и имя
- ZOD – знак зодиака
- DATE – дата рождения (год, месяц, число)

Программа выполняет следующие функции:
1. Ввод с клавиатуры данных в массив MASS, состоящий из 10 элементов типа ZNAK
2. Упорядочивание записей по дате рождения
3. Поиск и вывод информации о людях, родившихся под заданным знаком зодиака

## Usage
1. Сборка программы:
make

2. Запуск программы:./bin/program

3. Очистка собранных файлов: make clean

## Additional Notes
Программа разработана согласно модели КИС (Клиент-Интерфейс-Сервер):
- `main.c` - клиентская часть (взаимодействие с пользователем)
- `znak.h` - интерфейс (заголовочный файл с объявлениями)
- `znak.c` - серверная часть (реализация функций)

Сборка автоматизирована через Makefile и GitHub Actions.
